# AI Studio 前端实验项目

这是一个基于 Vue 3 + Vite 的本地图库匹配界面。用户输入自然语言后，后端通过 Gemini 提取关键词，再从已有图片标签中选择最接近的一张返回。

> 当前版本不会生成新图片，也没有向量检索。它是交互与工具调用实验，不是可直接上线的绘画服务。

## ✨ 核心特性

- **沉浸式暗黑美学**：全局采用富有质感的高级灰蓝、暗夜黑与毛玻璃（Glassmorphism）特效，去除了所有的冗余侧边栏，将焦点完全集中在生图交互视窗。
- **打字机动效沉浸交互**：包含气泡升起加载动效、底部毛玻璃遮罩以及基于 Markdown 的图文混排气泡框。
- **轻量 Markdown 展示**：支持当前后端返回的图片 Markdown；它不是完整 Markdown 解析器，不应用于展示不可信 HTML。
- **本地演示鉴权**：开发模式可以用环境变量指定演示账号；生产构建禁止自动注册固定账号。

## 🧩 核心组件流向

- **`App.vue`**：根布局组件，作为全屏 AI Studio 画板的框架容器。
- **`ChatBot.vue`**：居于大屏中央的核心聊天大脑。包含历史流记录、动画过渡、Markdown 编排与底层交互逻辑。
- **`api/agent.ts`**：RESTful 通信与数据层适配器。封装鉴权、拦截及与后端的 `TransformInterceptor` 包装格式接洽。

## 🚀 快速启动

1. **环境准备**
   确保系统已安装现代版本的 `Node.js`。

2. **安装依赖**

```bash
pnpm install
```

3. **连接后端**
   复制本地示例配置并替换演示密码：

```bash
cp .env.example .env.local
```

   请确保 [ai-studio-backend](https://github.com/YouRen1320/ai-studio-backend) 已在配置的地址运行。`VITE_*` 值会进入浏览器构建产物，不能用于保存生产密钥。

4. **启动开发服务器**

```bash
pnpm dev
```

项目通常会运行在 `http://localhost:5173` 或者因端口被占用自动顺延至 `5174` 等。

## 当前边界

- 生产构建尚未接入登录页面，自动创建演示账号只允许在 Vite 开发模式运行。
- 后端返回的会话标识只保存在当前页面内；刷新页面后不会恢复。
- 图片版权、访问控制、内容审核和用户数据删除流程尚未实现。
